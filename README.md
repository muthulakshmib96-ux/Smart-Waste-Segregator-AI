This project uses Google Teachable Machine to classify *Dry Waste* and *Wet Waste* using image-based AI.

## 🔗 AI Model Link (Trained Model)
https://teachablemachine.withgoogle.com/models/8xa80GQ2o/

## 📘 Project Description
- Class 1: Dry Waste  
- Class 2: Wet Waste  
- Model trained using webcam & uploaded images  
- AI predicts the waste category in real time

## 🚀 How It Works
1. Show the waste item to camera  
2. AI analyzes the image  
3. Output: Dry or Wet waste

## 🛠 Tools Used
- Google Teachable Machine  
- Web-based Image Classifier
